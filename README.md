# LaptopCheck — портативная утилита приёмки корпоративных ноутбуков

Запускается с USB-флешки на Windows 10/11 (x64) без установки. За 3–5 минут проводит
диагностику ноутбука и сохраняет акт приёмки (HTML + JSON) в папку `Reports` рядом с exe.

## Этапы мастера

| № | Этап | Что проверяется |
|---|------|-----------------|
| 1 | Паспорт устройства | Модель, серийный номер BIOS, CPU, ОЗУ; здоровье и циклы батареи; SMART, износ и температура дисков; устройства с ошибками в диспетчере; активация Windows, BitLocker, домен / Azure AD |
| 2 | Клавиатура и тачпад | Схема ANSI/ISO + Numpad, низкоуровневый перехват клавиш (Win, Alt+Tab, PrintScreen), 2-секундный детектор залипания, клики и прокрутка тачпада |
| 3 | Дисплей | Полноэкранные заливки: чёрный, белый, красный, зелёный, синий, серый 50 % |
| 4 | Веб-камера | Автопоиск камер, живое видео, разрешение и FPS |
| 5 | Звук | Тон 440 Гц отдельно в левый и правый канал, VU-метр микрофона, запись 3 с и воспроизведение |
| 6 | Порты и питание | AC Online в реальном времени, счётчик переподключений флешки и разных USB-портов, Wi-Fi и Bluetooth |
| 7 | Осмотр и акт | Чек-лист физического состояния, ФИО сторон, формирование акта |

На каждом этапе: **Подтвердить (ОК)**, **Зафиксировать дефект** (нужен комментарий), **Пропустить**.
Если устройства физически нет (камера, батарея, микрофон), этап получает статус «Устройство не обнаружено».

## Сборка в один exe

На машине с Windows 10/11 x64 и Python 3.11+ запустите `build.bat` либо выполните вручную:

```bat
python -m pip install -r requirements.txt
python -m PyInstaller --onefile --noconsole --uac-admin --clean --noconfirm --name LaptopCheck --exclude-module matplotlib --exclude-module PIL --exclude-module scipy --exclude-module pandas main.py
python tools\set_swaprun.py dist\LaptopCheck.exe
```

Результат — `dist\LaptopCheck.exe`. Скопируйте его на флешку; при запуске Windows запросит права
администратора (нужны для BitLocker и SMART-счётчиков).

Третья команда выставляет в заголовке exe флаг «запускать из файла подкачки», чтобы программа
не падала, когда флешку вынимают в тесте USB-портов.

## Запуск из исходников (для отладки)

```bat
python -m pip install -r requirements.txt
python main.py
```

Без прав администратора программа работает, но BitLocker, износ и температура дисков могут быть недоступны.

## Отчёт

`Reports\YYYY-MM-DD_<SerialNumber>_<Фамилия>.html` — самодостаточный файл (без внешних ресурсов),
открывается в любом браузере, кнопка «Печать / PDF» сохраняет его в PDF. Рядом кладётся `.json`
с сырыми данными. Существующие отчёты не перезаписываются (добавляется `_2`, `_3`…).

## Что важно знать

- **Временные файлы.** Сама программа пишет только в `Reports`. Но exe, собранный с `--onefile`,
  при каждом запуске распаковывает библиотеки в `%TEMP%\_MEIxxxxx` на диске ноутбука и удаляет их
  при выходе — так устроен PyInstaller. Чтобы распаковка шла на флешку, добавьте к команде сборки
  `--runtime-tmpdir .`, но тогда запуск будет заметно медленнее, а флешку нельзя будет вынимать в тесте USB.
- **Клавиша Fn** не посылает код в Windows — её проверяют сочетаниями (яркость, громкость).
- **Ctrl+Alt+Del** перехватить нельзя — это ограничение Windows.
- **Счётчик USB** видит флешки (съёмные диски). Номер физического порта определяется через PowerShell;
  если не удалось — считается просто число подключений.
- Антивирус может ругаться на неподписанный exe от PyInstaller с перехватом клавиатуры — при
  необходимости добавьте файл в исключения или подпишите сертификатом компании.

## Структура

```
main.py                    точка входа
laptopcheck/app.py         окно мастера, статусы, сбор данных для акта
laptopcheck/sysinfo.py     PowerShell-скрипты паспорта и разбор результатов
laptopcheck/keyhook.py     WH_KEYBOARD_LL через ctypes
laptopcheck/report.py      HTML/JSON акт
laptopcheck/steps/         этапы мастера (по файлу на этап)
tools/set_swaprun.py       пост-обработка exe
tests/                     python -m unittest discover tests
```
